# 🌍 EnviroAI — AI-Based Environmental Risk Intelligence System

## 📌 Project Overview
EnviroAI is a Machine Learning–based environmental intelligence system designed to predict air pollution levels and analyze environmental risk factors using environmental, weather, and satellite (NDVI) data.

The system will provide:
- PM2.5 prediction
- AQI prediction
- Environmental factor analysis
- Explainable AI using SHAP
- Interactive dashboard

---

## 🎯 Problem Statement
Air pollution prediction involves complex relationships between environmental factors such as temperature, humidity, wind speed, pollutant levels, and vegetation indices.

This project develops an AI-based predictive system to improve prediction accuracy and interpretability.

---

## 📊 Dataset Description
Dataset Name: data.csv  
Size: 180,644 rows × 8 columns  

Features:
- PM2.5
- PM10
- NO2
- Temperature
- Humidity
- Wind Speed
- NDVI
- Timestamp

The dataset combines air quality data, weather data, and satellite NDVI data.
