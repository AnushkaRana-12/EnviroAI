📌 Project Overview
EnviroAI is a Machine Learning–based environmental intelligence system designed to predict air pollution levels and analyze environmental risk factors using historical environmental, weather, and satellite (NDVI) data.

The system provides:
- 📊 PM2.5 pollution prediction  
- 🌱 Environmental factor analysis  
- ⚠️ Early warning insights  
- 🔍 Explainable AI using SHAP  

🎯 Problem Statement
Air pollution prediction involves complex, non-linear relationships between environmental factors such as weather conditions, pollutant levels, and vegetation indices.

Traditional methods fail to model these relationships effectively.

This project develops an **AI-powered predictive system** to improve both accuracy and interpretability.

🧠 Objectives
- Predict **PM2.5 levels** using machine learning  
- Analyze patterns using AQI, weather, and NDVI data  
- Improve performance with **ensemble learning (Random Forest)**  
- Provide **model explainability using SHAP**  
- Support environmental monitoring and planning  

🛠️ Tech Stack
- **Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn  
- **Visualization:** Matplotlib, Seaborn  
- **Environment:** Jupyter Notebook / Google Colab  
- **Explainability:** SHAP  

⚙️ Workflow
1. Data Collection & Integration  
2. Data Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Feature Engineering  
5. Model Training (Random Forest Regression)  
6. Model Evaluation (MAE, RMSE, R²)  
7. SHAP Analysis (Explainable AI)
